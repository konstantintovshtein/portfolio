GPU Sharing Platform — Stormhacks 2026

A full-stack hackathon build from scratch: a web app and a desktop app for sharing GPU power, with Solana wallet sign-in and payouts.

Overview

At Stormhacks 2026 our team built GPU sharing software from scratch. I worked as a full-stack developer on the team.

What I built

I worked on both the web app and the desktop app. I implemented Solana wallet authentication, so users sign in with their crypto wallet instead of a password, and set up payouts on the Solana Devnet test network.
